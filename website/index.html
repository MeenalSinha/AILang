AILang

An agentic-systems programming language where AI is a first-class construct instead of a library.

v0.1 — foundation release, no AI constructs yet

Today

v0.1 ships a complete, ordinary programming language: lexer, parser, semantic analysis, static type checking, a tree-walk interpreter, a CLI, a REPL, a formatter, and foundations for a package manager and a language server. No agent/model/workflow constructs exist yet — see the roadmap below for why that's intentional.

fn fib(n: int) -> int {
    if n < 2 { return n; }
    return fib(n - 1) + fib(n - 2);
}

for i in 0..10 {
    println(fib(i));
}

Tomorrow

agent Researcher {
    model GPT5
    memory persistent
    tools [search, browser]
}

workflow Paper {
    Researcher -> Writer -> Reviewer
}

Every phase of the v0.1 compiler was built so that adding agent, model, workflow, tool, memory, and the rest of the reserved AI-native keywords is a matter of adding new AST variants and interpreter dispatch arms — not a rewrite. See docs/roadmap.md.
